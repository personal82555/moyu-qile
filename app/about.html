🎮 三个游戏怎么玩

♟️ 象棋（AI 对战 / 双人同屏）

  • 规则：标准中国象棋，红先黑后，马跳日（蹩马腿）、象走田（塞象眼）、炮隔山打子、兵过河可横走；将死或困毙（无棋可走）判负。
  • 操作：点选己方棋子 → 绿色提示圈显示所有可走位置 → 点目标格完成走子。已选棋子再点一次可取消选中。
  • AI 棋力：内置搜索博弈引擎；难度下拉切换——简单、普通、困难。
  • 悔棋：一次撤回"你+AI"各一步；残局里悔棋不会拆掉残局的初始摆位。

⚫ 五子棋（AI 对战 / 双人同屏）

  • 规则：15×15 盘，黑白轮流落子，先连成五子（横/竖/斜任意方向）者胜；下满为平局。
  • 操作：点网格线交叉点落子；最后一手落子处会亮红点标示，胜利的五连外圈套红环。
  • AI：攻防评分选点；简单=随手，普通=综合攻防最强点，困难=防守权重加大的前瞻选点（会堵你的活四、连四）。

🚩 军棋 · 陆战棋翻棋（AI 对战 / 双人同屏）

  • 规则：全盘 50 枚棋子（每方 25 枚）背面朝上铺在棋盘上，开局全部盖着。轮到你就翻一张（翻到哪方的颜色，你就执哪方，先翻者定色）或移动一枚己方已翻开的棋子。
  • 等级（大吃小）：司令 › 军长 › 师长 › 旅长 › 团长 › 营长 › 连长 › 排长 › 工兵；同级相遇两败俱伤。
  • 特例
    • 工兵能挖地雷（唯一可吃雷的子），其他子碰雷会被炸掉；地雷不能移动。
    • 炸弹遇到任何棋子一起消失。
    • 吃掉对方军旗直接获胜；军旗不能移动。
  • 棋盘要点
    • 行营（圆圈）：空营可以走进去、也能走出来；营里的棋子不能被吃（安全屋）。有子的行营会套一圈琥珀虚线环并标「营」，一眼看得出这是受保护的棋子。
    • 大本营（四角方框）：可以摆子也可以走进去；进入后不能再移动（会标「本」）。
    • 铁路（黑色双轨）：工兵可沿铁路直行任意格，其他棋子一次只走一步。
    • 山界（中间横带）：只有两侧与中路三处可以通行。
    • 斜线：只有行营与四角兵站之间可以斜走。

  2. 碎片时间友好：单局 3–10 分钟一盘，有悔棋兜底；中途必须走开？点「💾 存档」或直接走，回来还能接着下。
  3. 双人对局零门槛：很多棋牌 App 两个人反而要分别注册账号联机——这里直接共用一块屏幕。
  4. 会越玩越懂：AI 教练每一步给出理由，棋力在菜鸟期被讲解带出来；每个游戏还有「📖 玩法」随时查规则。

💡 推荐摸鱼姿势：浏览器 PIN 这个标签页 → 工作窗口旁边放着。象棋困难级做大脑热身，五子棋做冥想，军棋翻棋在"远程会议走神"时惊喜更多。

❓ 常见问题

问题解答
怎么联机和朋友远程玩？目前主打同屏 + AI。远程建议用屏幕共享/投屏方式对玩。
AI 教练需要什么配置？任何 OpenAI 兼容接口都行：自定义 Base URL + Key + 模型名。面板里有「免费 获取KEY」入口。
进度会丢吗？不会。① 每走一步自动存局中快照，刷新/误关后重进会问「是否继续上一局」；② 也可以点「💾 存档」手动存（日期+时间命名），随时「恢复」；③ 离开未结束的对局会弹确认。
存档/战绩存在哪？能备份吗？存在服务器数据目录，每个游戏独立文件：chess-saves.json / chess-ranks.json 等。界面里「💾 存档 → ⚙ 存档路径」可自定义目录；直接复制该目录即完成备份。
中途被打断会丢局吗？不会。系统每分钟自动存档一次（覆盖同一份，列表里标「⏱ 自动」）；也可以点「💾 存档」手动存一份带时间戳的。回来在「💾 存档」里点「恢复」即可继续。
自动存档会越存越多吗？不会。每个游戏只保留一份自动存档，每分钟覆盖更新；手动存档则各自独立保留（最多 100 份/游戏）。
倒计时超时怎么办？超时会弹「超时判负」并自动记录一局负，可以点「⟳ 重新开始」再来或者在「💾 存档」里恢复更早的进度。
军棋为什么行营是空的？开局 行营一律不放子（标准规则：行营是安全屋，留空才公平）。行营里的棋子是走进去的，进去后不能被吃。
军棋大本营能放子吗？可以。大本营开局就有棋子，也能走进去；但进去以后不能再移动，要想好再进。
切换游戏会丢局吗？不会立刻丢：会先弹确认框。确认离开后仍有局中快照，重新进入可以继续。
